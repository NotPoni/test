# VOID Bot (discord.py)

Модули: защита (anti-nuke), заявки/повышения, ивенты, статистика персонала, выговоры, магазин баллов + рулетка, личные взаимодействия.

## Запуск
1. Discord Developer Portal → Bot → включить **Server Members Intent** и **Message Content Intent**.
2. Права бота: Administrator (или Manage Roles, Ban/Kick, View Audit Log, Manage Channels, Manage Threads, Send Messages). Роль бота выше всех управляемых ролей.
3. `cp .env.example .env` и заполнить (токен, ID сервера, роли, каналы).
4. `pip install -r requirements.txt` → `python bot.py`

## Панели (команды ставят панели в канал; кнопки работают после перезапуска)
| Команда | Что делает |
|---|---|
| `/panel_protection` | защита: бан/кик/врем.бан по событиям, вайтлист (настройки — только владелец сервера) |
| `/panel_promotion` | центр заявок: Tier I-III, подразделения Rec/Tch/High, MCL Test |
| `/panel_app_settings` | форма заявок, статус набора, сброс КД |
| `/panel_events` | ивенты: регистрация, РП, ветки, проверка откатов |
| `/panel_stats` | мониторинг: рекрутёры, тир-чекеры, войс, инактив, снимок войса, проверка игрока |
| `/panel_warns` | выговоры 1/3, 2/3, 3/3 (отстранение от каптов) |
| `/panel_shop`, `/panel_shop_admin` | магазин, баллы за войс, рулетка, снятие выговора за баллы |
| `/panel_interactions`, `/set_guides` | отпуск, портфель, откат, AFK, гайды |
| `/create-capt`, `/create-mcl` | списки записи: кнопки записи, авто-группа по роли, замена, закрытие |
| `/list-kick`, `/list-close` | убрать участника / закрыть открытый список в текущем канале |

## Быстрая настройка (`!canal`)
1. Выдайте боту права **Manage Roles** и **Manage Channels** (лучше Administrator) и поставьте его роль выше ролей, которые он будет выдавать.
2. Напишите на сервере `!canal` от имени админа.
3. Бот создаст роли и каналы (уже существующие с такими же именами он переиспользует) и пришлёт файл `ids.env`.
4. Вставьте содержимое `ids.env` в `.env`, перезапустите бота.

Команду можно запускать повторно: дублей не будет. Бот не меняет `.env` сам, так как там секреты.

## Важно
- Защита карает за **любой** бан/кик/создание канала и т.д. сверх лимита. Добавьте доверенных модераторов в вайтлист, иначе бот кикнет их.
- Админ = право Administrator или роль `ADMIN_ROLE_ID`.
- В форме Discord максимум 5 вопросов.
- Баллы начисляются при выходе из войса (`/panel_shop_admin` → Фарм).
- Списки CAPT/MCL хранятся в БД: после перезапуска кнопки продолжают работать. Список автоматически закрывается через 12 ч после времени старта.
- Если задан `PORT`, бот поднимает `/health` для проверки работоспособности хостингом.
