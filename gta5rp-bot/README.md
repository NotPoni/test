# GTA 5RP Family Bot

Заявки и обзвон (как в вашем bot_1.py), CAPT-меню с веткой, Инактив-панель, голосовые баллы + магазин,
личные кабинеты и `!setup`, который сам создаёт роли и каналы и привязывает их к командам.
Системы сборов (`/mcl`, `/zonewars`, `/сбор`) нет.

## Запуск
1. `pip install -r requirements.txt` (нужен **discord.py ≥ 2.6** из-за меню CAPT)
2. `.env.example` → `.env`, впишите `DISCORD_TOKEN` и `GUILD_ID`.
3. Developer Portal → Bot → включите **Server Members Intent** и **Message Content Intent**.
4. Пригласите бота с правом **Administrator**, роль бота — как можно выше.
5. `python main.py`, затем на сервере под админом: **`!setup`**

## `!setup`
Для каждой роли/канала: уже привязанное → ID из `.env` → существующее по названию → создать. Повторный запуск безопасен.

| Команда | Действие |
|---|---|
| `!setup` | роли, категории, каналы, права, панели |
| `!setup force` | то же + пересобрать права (один раз после обновления, чтобы в #capt писали в ветках) |
| `!setup panels` | переотправить панели |
| `!setup status` | что к чему привязано |
| `!setup bind <ключ> <@роль/#канал>` | привязать вручную |
| `!panel apply\|support\|afk\|shifts\|shop\|cabinet\|rules` | панель в текущий канал |

## Заявки
Панель в #подать-заявку: **RP+CAPT** (5 вопросов) и **RP** (3 вопроса). Создаётся `заявка-N` (видят заявитель и штаб),
заявитель получает роль «Подал заявку», пингуются High и Recruiter.
1. **Взять на рассмотрение** → кнопки **Принять / Отклонить / Обзвон / Обновить / Закрыть**.
2. **Принять**: +1 балл, роли семьи и Newbie, снимается «Подал заявку», ЛС кандидату, канал удаляется (транскрипт HTML уходит в #лог-заявок).
3. **Отклонить**: причина → ЛС кандидату, транскрипт, канал удаляется.
4. **Обзвон**: выбор канала; если кандидат в голосовом — его перемещают, иначе приглашение в заявку и в ЛС.
5. **Закрыть**: транскрипт (файл только вам) / закрыть с логом / удалить канал.
Текст панели — `texts.py` (`APPLY_INFO`, взят из вашего bot_1.py).

## Инактив-панель
Панель «⚙️ Инактив-панель» с кнопками **AFK** (срок из списка или свой), **Инактив** (причина + дни, уходит на одобрение
в #логи-afk), **Вернулся**, **Модерация** (для сотрудников: снять статус у участника, обновить панель, запросы на инактив).
Роли AFK/Инактив ставятся и снимаются сами, список в панели обновляется. В #варны приходит предупреждение, если человек
сидит в голосовом с выключенным звуком дольше `AFK_WARN_MINUTES` без статуса (в игре Discord-бот это увидеть не может).

## CAPT
`/capt title:"ЗА ОСОБУ vs hated" start_time:"18:20"` — меню-контейнер + ветка; сотрудник реакциями ✅/❌ (или 1️⃣…9️⃣) формирует
состав, кнопка «Завершить» начисляет баллы (`CAPT_REWARD`).
